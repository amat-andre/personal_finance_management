# Personal Finance

Консольное backend-приложение на Java 17 для управления личными финансами. Поддерживает нескольких пользователей, доходы и расходы, категории, бюджеты, статистику, оповещения, переводы между кошельками, JSON-персистентность и переносимые снимки данных.

Проект разделён на слои модели, сервисов, хранилищ и CLI. Во время работы данные находятся в памяти; при регистрации, сохранении, смене пользователя и выходе они записываются в JSON.

## Возможности

- регистрация и стабильная авторизация по логину и паролю;
- PBKDF2-хеширование паролей со случайной солью;
- отдельный кошелёк для каждого пользователя;
- учёт доходов и расходов с категориями, описаниями, датами и UUID;
- создание, переименование и удаление категорий;
- установка, изменение и удаление бюджетов;
- общий баланс, суммы доходов и расходов, сводки по категориям;
- расчёт по нескольким выбранным категориям без учёта регистра;
- табличный вывод в терминал и текстовый файл;
- предупреждения при 80 % бюджета, превышении лимита, нулевом балансе и расходах выше доходов;
- переводы по логину с расходом у отправителя и доходом у получателя;
- автоматическое сохранение и загрузка кошелька;
- экспорт и безопасный импорт JSON-снимков;
- устойчивый CLI с `help`, примерами и понятными ошибками;
- 55 автоматических тестов, Checkstyle и GitHub Actions.

## Требования и зависимости

Необходимы:

- **JDK 17 или новее**;
- доступ в интернет при первой сборке для загрузки Maven и зависимостей.

Отдельно устанавливать Maven не требуется: в репозитории находится Maven Wrapper. Внешние библиотеки также устанавливать вручную не нужно — `./mvnw` автоматически скачает их из Maven Central.

Основные зависимости:

| Зависимость | Назначение |
|---|---|
| Jackson Databind 2.18.2 | Сериализация и десериализация JSON |
| JUnit Jupiter 5.11.4 | Unit- и интеграционные тесты |
| Checkstyle 10.21.2 | Автоматическая проверка стиля |

Версии зафиксированы в `pom.xml`. Все зависимости сборки описаны там же.

## Сборка и запуск

### Linux / macOS

```bash
./mvnw clean package
java -jar target/personal-finance-1.0-SNAPSHOT.jar
```

### Windows

```bat
mvnw.cmd clean package
java -jar target/personal-finance-1.0-SNAPSHOT.jar
```

Если Maven уже установлен, команды `./mvnw` и `mvnw.cmd` можно заменить на `mvn`.

По умолчанию пользовательские JSON-файлы сохраняются в каталог `data` внутри текущей рабочей директории. Другой каталог можно указать системным свойством:

```bash
java -Dfinance.data.dir=/path/to/data -jar target/personal-finance-1.0-SNAPSHOT.jar
```

## Быстрый старт

После запуска введите команды построчно:

```text
register alice secret
login alice secret
income "Зарплата" 60000 "Основная работа"
expense "Еда" 1200 "Продукты"
budget "Еда" 15000
stats
exit
```

Команда `help` показывает список команд и встроенные примеры. Приглашение `alice> ` означает, что операции выполняются в кошельке пользователя `alice`.

## Команды

| Команда | Назначение |
|---|---|
| `help` | Показать справку и примеры |
| `register логин пароль` | Зарегистрировать пользователя и создать кошелёк |
| `login логин пароль` | Войти и загрузить сохранённый кошелёк |
| `logout` | Сохранить кошелёк и выйти из аккаунта |
| `income "категория" сумма ["описание"]` | Добавить доход |
| `expense "категория" сумма ["описание"]` | Добавить расход |
| `budget "категория" лимит` | Создать или изменить бюджет |
| `remove-budget "категория"` | Удалить бюджет, сохранив операции |
| `rename-category "старое" "новое"` | Переименовать категорию во всех операциях и бюджетах |
| `delete-category "категория"` | Удалить категорию, её операции и бюджет |
| `transfer логин сумма` | Перевести средства другому пользователю |
| `stats` | Показать полную статистику в таблицах |
| `stats "категория" ["категория" ...]` | Подсчитать итоги по выбранным категориям |
| `balance` | Показать текущий баланс |
| `report "путь к файлу"` | Сохранить текстовый отчёт |
| `export "путь к JSON"` | Экспортировать переносимый снимок кошелька |
| `import "путь к JSON"` | Импортировать снимок текущего пользователя |
| `save` | Немедленно сохранить кошелёк |
| `exit` | Сохранить кошелёк и завершить приложение |

### Примеры

Доход и расход:

```text
income "Бонус" 5000,50 "Премия"
expense "Коммунальные услуги" 4500 "Счёт за месяц"
```

Редактирование категорий и бюджета:

```text
rename-category "Еда" "Продукты"
budget "Продукты" 20000
remove-budget "Продукты"
```

Выборка по нескольким категориям:

```text
stats "Зарплата" "Бонус" "Продукты"
```

Перевод другому пользователю:

```text
transfer bob 2500
```

Текстовый отчёт и JSON-снимок:

```text
report "reports/finance.txt"
export "backups/alice.json"
import "backups/alice.json"
```

**Внимание:** `delete-category` удаляет все операции этой категории и её бюджет. Для удаления только лимита используйте `remove-budget`.

## Правила ввода

- Логин содержит от 3 до 32 букв, цифр, дефисов или подчёркиваний и нормализуется к нижнему регистру.
- Пароль содержит не менее 4 символов. Открытый пароль нигде не сохраняется.
- Название категории не может быть пустым; сравнение категорий не зависит от регистра.
- Аргументы с пробелами заключаются в двойные кавычки.
- Сумма операции должна быть больше нуля.
- Бюджет может быть нулевым, но не отрицательным.
- Разрешены точка и запятая как десятичный разделитель, максимум два знака после разделителя.
- Неизвестная команда или категория не завершает цикл: приложение выводит сообщение и принимает следующую команду.
- Нельзя переименовать категорию в уже существующее имя или перевести деньги самому себе.

Денежные расчёты выполняются через `BigDecimal`, а не `double`.

## Статистика и оповещения

Команда `stats` выводит:

1. общий доход;
2. доходы по категориям;
3. общие расходы;
4. расходы по категориям;
5. текущий баланс;
6. лимит, расход и оставшийся бюджет по каждой категории.

Фрагмент отчёта:

```text
Бюджет по категориям:
+-----------+---------+--------+---------------------+
| Категория | Лимит   | Расход | Оставшийся бюджет   |
+-----------+---------+--------+---------------------+
| Еда       | 4000.00 | 800.00 | 3200.00             |
+-----------+---------+--------+---------------------+
```

При выборке по нескольким категориям найденные суммы рассчитываются, а отсутствующие категории перечисляются отдельно.

Оповещения формируются сразу после операции или изменения бюджета:

- при первом переходе через порог 80 % лимита;
- при превышении лимита с указанием суммы перерасхода;
- при нулевом балансе;
- при превышении общих расходов над доходами.

## Хранение, экспорт и импорт

### Автоматическое сохранение

Кошелёк записывается в JSON:

- при регистрации;
- по команде `save`;
- по команде `logout`;
- по команде `exit`;
- после перевода для обоих участников;
- после успешного импорта.

При `login` сохранённые операции, бюджеты и хеш пароля загружаются обратно. Имя файла формируется из безопасной Base64-формы логина. Запись выполняется через временный файл и атомарную замену, если файловая система её поддерживает.

### Различие `report` и `export`

- `report` создаёт человекочитаемый текстовый отчёт со статистикой.
- `export` создаёт JSON-снимок, который можно загрузить командой `import`.

Импорт полностью разбирает и проверяет снимок до изменения текущего кошелька. Чужой или повреждённый файл отклоняется. Логин и хеш пароля текущего пользователя при импорте сохраняются; восстанавливаются только операции и бюджеты.

## Тестирование и проверка качества

Запуск всех 55 тестов:

```bash
./mvnw test
```

Проверка стиля:

```bash
./mvnw checkstyle:check
```

Полная проверка: Checkstyle, тесты и сборка исполняемого JAR:

```bash
./mvnw clean verify
```

Тесты находятся в `src/test/java` и включают:

- unit-тесты модели, авторизации, расчётов, бюджетов и оповещений;
- тесты редактирования категорий и переводов;
- тесты JSON-сохранения, экспорта и импорта;
- интеграционные CLI-тесты с реальными входными командами и временными файлами;
- проверки восстановления после перезапуска и отказа от повреждённых данных.

Файл `.github/workflows/ci.yml` запускает `./mvnw clean verify` на JDK 17 для каждого push в `main`/`master` и каждого pull request.

## Архитектура и структура

```text
CLI (console)
    ↓
Бизнес-логика (service)
    ↓
Доменная модель (model)
    ↑
Интерфейсы хранилищ (repository, persistence)
    ↑
In-memory и JSON-реализации
```

```text
.
├── src/main/java/ru/example/finance/
│   ├── console/          # CLI, разбор и валидация команд, табличные отчёты
│   ├── model/            # Пользователь, кошелёк, категория, операция
│   ├── repository/       # Интерфейс и in-memory репозиторий пользователей
│   ├── service/          # Авторизация, финансы, статистика, переводы
│   ├── persistence/      # JSON-хранение и переносимые снимки
│   └── PersonalFinanceApplication.java
├── src/test/java/        # Unit- и интеграционные тесты
├── .github/workflows/ci.yml
├── checkstyle.xml
├── pom.xml
└── README.md
```

Точка входа — `PersonalFinanceApplication`. Она создаёт хранилища и сервисы, связывает зависимости и запускает консольное приложение.
